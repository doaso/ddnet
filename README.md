## Overview
A custom server-side modification designed to enhance the MMORPG experience. This game mode features a comprehensive account system, a five-tier administration hierarchy, an in-game store, dedicated farming zones, casino duels, and much more
![screenshot](./screenshots.gif)
## Build
```sh
git clone https://github.com/doaso/ddnet.git
cd ddnet
cmake -B build
cmake --build build
```
